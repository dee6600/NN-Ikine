# Technical report: Learning IK by Imitating a Numerical Solver

`main.pdf` is the compiled report. Everything in it is produced from the original project artifacts in `../devlopment_project` by the scripts in `code/`.

| Path | Contents |
| --- | --- |
| `main.tex`, `refs.bib` | LaTeX source, IEEEtran two-column (compiles with `tectonic --keep-intermediates main.tex` or `pdflatex` + `bibtex`) |
| `main_long.tex`, `main_long.pdf` | Longer 10-page version with extra figures, tables and appendices |
| `main_article_backup.tex`, `main_before_cleanup.tex` | Earlier drafts (safe to delete) |
| `code/ikcore.py` | RRR/RPP kinematics, closed-form IK, Python replica of RTB `ikine` (LM), Keras-HDF5 → NumPy MLP loader |
| `code/audit.py` | Part I: dataset audit, solver-failure replication, re-evaluation of all 7 shipped models, provenance checks → `results/audit.json` |
| `code/improved.py` | Part II: controlled study (labels × loss × output head × 3 seeds), scaling, warm-start hybrid, latency → `results/improved.json` |
| `code/figures.py`, `code/make_tables.py` | Regenerate `figures/*.pdf` and `tables/*.tex` from the results |

## Reproduce

```bash
python3 -m venv venv && venv/bin/pip install h5py numpy pandas scipy scikit-learn matplotlib torch
cd code
../venv/bin/python audit.py         # ~30 s
../venv/bin/python improved.py      # ~45 min on an M1 Pro CPU
../venv/bin/python figures.py && ../venv/bin/python make_tables.py
cd .. && tectonic --keep-intermediates main.tex
```

TensorFlow is not required: the Keras weights are read directly from the `.h5` files.
